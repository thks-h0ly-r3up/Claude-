# 7HE H0LY R3UP Guide

Static chatbot. No server, no API key.

- Open `chatbot/index.html` in a browser, or publish with GitHub Pages.
- Your story lives in `testimony.js`. The bot shows it as yours and never invents one.
- Topics live in `kb.js`. Add an entry with `keys`, `body`, `step`, `verify`.
- Test matching: `node chatbot/test.js`
- Business model: `docs/business-model.md`
